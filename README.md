# cpp-ARPRO

ECNの授業で作成したC++のプログラムです．

授業資料は[こちら](https://github.com/aGotelli/ARPRO).

## プロジェクト構成

### Battleship

戦艦ゲームのC++実装です.

- [main.cpp](https://github.com/soso0024/cpp-ARPRO/blob/main/Battleship/main.cpp)
- [include](https://github.com/soso0024/cpp-ARPRO/tree/main/Battleship/include)

### find_the_number

数当てゲームです.

### guess_the_number

別の数当てゲームです.

## インストールと実行
- battleship
```bash
git clone https://github.com/soso0024/cpp-ARPRO.git
cd cpp-ARPRO/Battleship
cmake ..
make
./battleship
```
- find_the_number
```bash
git clone
cd cpp-ARPRO/find_the_number
cmake ..
make
./find_the_number
```
- guess_the_number
```bash
git clone
cd cpp-ARPRO/guess_the_number
cmake ..
make
./guess_the_number
```

## 使用技術
- 言語：C++
- ビルドツール：CMake
