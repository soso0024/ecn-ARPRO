コンピュータに数を当てさせるゲームです.


## 🛠 インストールと実行

### battleship

```bash
git clone https://github.com/soso0024/cpp-ARPRO.git
cd cpp-ARPRO/Battleship
cmake ..
make
./battleship
```

### find_the_number

```bash
git clone https://github.com/soso0024/cpp-ARPRO.git
cd cpp-ARPRO/guess_the_number
cmake ..
make
./guess_the_number
```

### guess_the_number

```bash
git clone https://github.com/soso0024/cpp-ARPRO.git
cd cpp-ARPRO/guess_the_number
```
