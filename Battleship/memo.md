## `std::vector` と `.push_back` メソッド

C++において、`.push_back` は `std::vector` クラスのメンバ関数の一つで、ベクトル（動的配列）の末尾に新しい要素を追加するために使用されます。この関数により、ベクトルは自動的にリサイズされ、新しい要素が末尾に挿入されます。

### 使用例

```cpp
std::vector<int> v; // 空の整数型ベクトルを作成
v.push_back(10);    // ベクトルの末尾に10を追加
v.push_back(20);    // ベクトルの末尾に20を追加
```

- このコードを実行すると、v ベクトルは {10, 20} の内容を持つことになります。

## オーバーライドとは？

オーバーライドは、サブクラスがベースクラスのメソッドを新しい実装で置き換えるオブジェクト指向プログラミングの概念です。

### どのように機能するのか？

- ベースクラスで `virtual` キーワードを使ってメソッドを定義します。
- サブクラスで同じ名前のメソッドを `override` キーワードを使って実装します。

### なぜ使用するのか？

- 異なるクラスで共通のインターフェースを持ちながら、特定のクラス固有の振る舞いを実現するため。
- ポリモーフィズムを活用して、コードの再利用性と柔軟性を高めるため。

### 例

```cpp
class Base {
public:
    virtual void show() {
        std::cout << "Base class show" << std::endl;
    }
};

class Derived : public Base {
public:
    void show() override {
        std::cout << "Derived class show" << std::endl;
    }
};

int main() {
    Base* base_ptr = new Derived();
    base_ptr->show();  // "Derived class show" が出力される
    delete base_ptr;
}
```

## AIの攻撃がHitした場合の攻撃パターン

1. 最後のヒット位置の周囲の未攻撃セルを特定する。
2. その未攻撃セルの中からランダムに選択し攻撃する。

アルゴリズムの擬似コード

```cpp
if 最後のヒット位置が有効（-1, -1 でない）:
    周囲のセルを特定する
    未攻撃のセルをリストアップする
    未攻撃のセルの中からランダムに選択する
else:
    未攻撃のセルをランダムに選択する
```
